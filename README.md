# Indian Railway Tracker

Tracking trains across the Indian Railway network using data from public APIs.

A passion project.

Live at [indian-railway-tracker.vercel.app](https://indian-railway-tracker.vercel.app)

Still under construction. The page runs 12951, the Mumbai Rajdhani, on its real timetable with a simulated feed, because a static page cannot hold an API key. The estimate, the arrival times and the error band are the code that will run against live feeds.

The build lives in [train-tracker/](train-tracker/). The public page lives in [site/](site/).
